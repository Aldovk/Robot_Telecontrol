# README - Robotis OpenRB-150
Se utilizó la placa de desarrollo openrb-150 producida por Robotis para el control de los servomotores dynamixel AX12 y XL320 en paralelismo.
****
**Links**

OpenRB-150: https://docs.robotis.com/docs/parts/controller/openrb-150/
 
Dynamixel AX12: https://docs.robotis.com/docs/dxl/model_reference/ax_series/ax-12a/

Dynamixel XL320: https://docs.robotis.com/docs/dxl/model_reference/x_series/xl_series/xl320/

****
## Importante:
Ambos tipos de servomotores dynamixel operan a distintos nivels de voltaje y protocols de comunicación.
_Los servomotores AX12 operan a 11.1V con Protocolo 1.0 y los XL320 operan a 7.4V con Protocolo 2.0._
