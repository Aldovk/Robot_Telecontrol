# README Configuración ATMega328P
En este script se tiene tanto el archivo de configuración del _Arduino Mega_ como dispositivo ISP y la programación del chip _ATMega328P_ como si fuese de una placa de desarrollo Arduino UNO. De esta manera se puede programar mediante su propio ArduinoIDE de una manera más sencilla y repetible.
****
_Es necesario asegurarse que los pines RESET, SCK, MISO y MOSI se encuentren correctamente conectados._
Los archivos designados como Placa_sensado_V# son los script para configurar el Circuito de comunicación como si se tratase de un Arduino UNO para esta aplicación de la recepción y escalado de los valores analógicos de los sensores hápticos para su posterior comunicación a la placa de desarrollo de Robotis OpenRB-150.
